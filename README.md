🍷 Wine Quality Prediction using Machine Learning

📌 Project Overview

This project predicts wine quality using machine learning based on physicochemical properties such as acidity, sugar, pH, alcohol, and sulphates. Data preprocessing, visualization, and model training were performed to build an accurate wine quality prediction model.

🎯 Objectives

✔ Predict wine quality
✔ Perform data preprocessing
✔ Visualize important features
✔ Train classification model
✔ Evaluate model performance
